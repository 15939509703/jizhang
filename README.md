# 记账小程序

这是一个微信小程序原生前端起步工程，包含登录、首页、记一笔、账单、统计、预算、账户、账本和设置页。

## 版本管理

小程序使用 GitHub 仓库的独立 `mini-program` 分支，与后端 `dev` 分支互不共享文件历史。

只克隆小程序代码：

```bash
git clone --single-branch --branch mini-program \
  git@github.com:15939509703/jizhang.git jizhang-mini-program
```

进入小程序目录后，正常执行 `git pull` 只会更新 `mini-program` 分支。
